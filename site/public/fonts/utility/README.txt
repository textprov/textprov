TextProv Utility P9E fonts, version 1.000

Development, debugging and demonstration adjuncts. Human U+E0100 keeps
the original outline; AI U+E0101 adds a visible sawtooth cue. Applications
choose their own provenance presentation. Cues declare provenance and
do not authenticate authorship. These are Regular Latin subsets.

Install each TTF in your operating system or use WOFF2 with @font-face.
Base character + selector is canonical. Registry-allocated AI PUA aliases
are available for compatibility. Only Human and AI are TextProv states.
Source per-glyph advances and line metrics are retained; marked runs
can shape differently (for example kerning or ligatures).

TextProv Sans Utility P9E — derived from Source Sans 3
TextProv Serif Utility P9E — derived from Source Serif 4
TextProv Fixed Utility P9E — derived from IBM Plex Mono
TextProv Mono Utility P9E — derived from Source Code Pro
TextProv Proportional Utility P9E — derived from Atkinson Hyperlegible

Each family folder in the bundle contains its full original OFL.txt and
README.txt with pinned source attribution. All source fonts and these
derivatives are SIL Open Font License 1.1 fonts. Sources and output hashes
are recorded in sources.json. Patches use FontTools directly and are
independent of Nerd Fonts or its font-patcher.
