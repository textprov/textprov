An open protocol for in-band provenance

Text that remembers

TextProv marks whether text was written by a person, generated by a machine, or has an unknown origin. The provenance travels with the text as Unicode.

The concept

Provenance should travel
with the words.

Mark

A producer adds a Unicode selector to each non-whitespace grapheme.

Carry

The signal survives ordinary copy, paste, files, and plain-text storage.

Reveal

A website, editor, or font can show the state without changing the words.

mark→copy→render

Use it on the web

No font. No framework.
Two files.

The browser decorator turns in-band marks into semantic spans with a stable data-prov attribute.

<link rel="stylesheet" href="textprov.css">
<script src="textprov.js"></script>

<script>textprov.render(document.body);</script>
