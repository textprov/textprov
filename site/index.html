TextProv

An open protocol for in-band provenance. A run of characters can say whether a person wrote it, a machine generated it, or its origin is unknown. The state travels in the text as Unicode code points, so it survives copy, paste, and plain-text storage.

Contract v1 · Registry v1 · MIT licensed

No install or special font needed. This demo runs in your browser; it does not send your text to a server.

Use it

Reading marked text

In a browser, no font required:

<link rel="stylesheet" href="textprov.css">
<script src="textprov.js"></script>
<script>textprov.render(document.body);</script>

On a server:

import textprov
textprov.to_html("f\U000E0101oo")
# '<span class="prov prov-ai" data-prov="ai">f\U000E0101</span>oo'

Both emit the same markup:

<span class="prov prov-ai" data-prov="ai">TEXT</span>

data-prov is the contract. The classes exist so CSS can show the state; the bundled stylesheet is one choice of style, not part of the protocol.

Producing marked text

Marking text needs the registry and nothing else — no font, no shaping engine, no build step. The reference producer ships in the Python package and its CLI:

python3 -m textprov -o marked.txt mark --ai draft.txt
